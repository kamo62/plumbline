# Security policy

Do not disclose suspected vulnerabilities, credentials or sensitive data in public
issues, discussions or pull requests. For this GitHub repository, use the
[private security advisory form](https://github.com/kamo62/plumbline/security/advisories/new)
if private vulnerability reporting is available to you. Include the affected version
or commit, impact, reproduction steps using synthetic data and any proposed fix.
Do not include live credentials or data belonging to others.

If GitHub does not offer the form, do not post the vulnerability publicly while
seeking a private reporting route. GitHub advisory availability and response times
are not guaranteed by this document.

The application is under development. See the [README](README.md) for current
access-control and deployment limitations. A local test or mock does not establish
security of a live deployment.
